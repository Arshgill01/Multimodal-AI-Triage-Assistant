# Skill: Hackathon Refinement

Use this skill when choosing between possible improvements.

## Prefer changes that are

- visible in the demo
- easy to explain to judges
- clearly useful in practice
- grounded in existing code
- finishable quickly and safely

## Highest-value themes

1. make strongest existing ideas truly live
2. reduce demo brittleness
3. improve clarity of story and docs
4. strengthen trust / explainability / override path
5. strengthen MCI operational storytelling

## Avoid

- speculative rewrites
- broad refactors with low judge payoff
- hidden improvements that do not change the live experience
